# Nexon Reconciliation Skills

This repository contains two separate Codex skills.

Do not install this repository from the repo root. The root contains multiple
`SKILL.md` files, so Codex needs a URL that points to one skill directory.

## Install URLs

Use these skill-directory URLs separately:

- `https://github.com/ramg-awasthi/nexon-recon-skills/tree/main/nexon-reconciliation`
- `https://github.com/ramg-awasthi/nexon-recon-skills/tree/main/nexon-telco-parsers`

## Contents

- `nexon-reconciliation`: supervisor-facing reconciliation workflow skill with deterministic scripts.
- `nexon-telco-parsers`: provider parser routing and parser migration skill.
